# Incidencias de red de un operador móvil · MCDI500

Proyecto del módulo **Programación para la Ciencia de Datos (MCDI500)** del Magíster en Ciencia de Datos e Inteligencia Artificial, Universidad Andrés Bello.

- **Integrante:** Edgar Arcia Velásquez ([@edgararciav-cpu](https://github.com/edgararciav-cpu)). Trabajo individual (Grupo 6), informado al docente.
- **Docente:** Dr. Omar Salinas Silva.
- **Datos:** incidencias de red registradas por el centro de operaciones (NOC) de WOM en octubre de 2026, anonimizadas y con autorización de la empresa.

> En construcción: este README se completa al cerrar la Fase 2, con la problemática, los objetivos y las instrucciones de ejecución.

## Estructura

```
data/raw/        datos de entrada (anonimizados), sin modificar
data/processed/  datos después de la limpieza y transformación (F2)
docs/            diccionario, bitácora de decisiones y metadatos
src/             funciones reutilizables del proyecto
scripts/         preparación previa de los datos (anonimización)
F1/ F2/ F3/ F4/  un notebook por fase
```

## Convención de commits

`docs:` documentación · `data:` datos · `feat:` código nuevo · `fix:` correcciones · `test:` pruebas
